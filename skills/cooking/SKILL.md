# Cooking

Meal planning, grocery lists, and a recipe archive, all stored as Markdown in
one data repo. This file only routes. Open the matching workflow before acting.

## Data root

`~/kitchen` (a symlink to the kitchen repo). If it does not exist, stop and
tell the user to clone or link it. Never guess another location.

| Path | Purpose |
|:--|:--|
| `preferences.md` | household size, diets, dislikes, time caps. Read before planning. |
| `pantry.md` | staples always on hand. Excluded from grocery lists. |
| `stores.md` | store list and aisle order. Controls grocery grouping. |
| `recipes/<category>/<slug>.md` | one recipe per file. |
| `recipes/INDEX.md`, `recipes/index.json` | generated by `scripts/build_index.py`. |
| `recipes/drafts/` | untested or imported recipes, not used for planning. |
| `plans/rotation.md`, `plans/YYYY-Www.md` | go-to set, and one plan per ISO week. |
| `grocery/YYYY-MM-DD.md` | one list per shopping trip. |

## Routing

| User intent | Open |
|:--|:--|
| plan the week, what should we eat, menu for the next N days | `workflows/plan-meals.md` |
| grocery or shopping list, what do I need to buy | `workflows/build-grocery-list.md` |
| save, add, import, write down this recipe | `workflows/add-recipe.md` |
| find a recipe, what can I make with X, something quick or vegetarian | `workflows/find-recipe.md` |
| I made X, rate it, note a tweak, promote from drafts | `workflows/after-cooking.md` |

Formats and vocabularies: `references/recipe-format.md`,
`references/conventions.md`, `references/grocery-categories.md`.
Blank files: `templates/`.

## Hard rules

1. Read `preferences.md` and `pantry.md` before drafting any plan or list.
2. Search recipes with `scripts/query.py` or `grep -ril` over `recipes/`.
   Do not open recipe files one by one to browse.
3. Never overwrite an existing recipe without showing the diff and getting a yes.
4. Present a draft plan or list and get confirmation before writing the file.
5. Name plans and lists by date, per `references/conventions.md`.
6. New recipes go to `recipes/drafts/` unless the user says they have cooked it.
7. After any recipe add or edit, run `scripts/lint_recipes.py`, then
   `scripts/build_index.py`. If Python is unavailable, update `INDEX.md` by hand
   and say so.
8. Every ingredient line must follow the grammar in `conventions.md`. Tags
   must come from its vocabulary; add to the vocabulary first if needed.

## Scripts

Stdlib Python, in this skill's `scripts/` directory. Paths default to
`~/kitchen/recipes`; pass a directory to override.

```
python3 scripts/lint_recipes.py            # validate every recipe, non-zero on errors
python3 scripts/build_index.py             # write recipes/INDEX.md and recipes/index.json
python3 scripts/query.py --ingredient chicken --tag weeknight --max-time 45
python3 scripts/query.py --any-ingredient rice --any-ingredient pasta --not-made-since 2026-06-01
```
